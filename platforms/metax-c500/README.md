# 沐曦－曦云 C500

负责人：用户指定的另一位队友，GitHub 用户名待确认。本实验库分别维护本平台与天数 BI-V150 的环境、分析、证据和中文报告，框架及算子代码在团队共用代码库协作。

当前尚未收到 C500 的设备环境、优化代码版本、准确率或官方吞吐原件，因此本页不填写性能数字。

队友接入后请在本目录补充：

1. 环境与基线：设备数量/显存、CPU配额、软件版本、比赛分支和精确源码身份。
2. 实现入口：共用的 `FlagOS-S2-vllm-plugin-FL`、`FlagGems` 仓库中实际使用的 commit 及启用方式；不要求另设平台分支。
3. 实验记录：唯一UTC run ID、官方命令、原始CSV/日志、准确率、源码哈希及负结果。
4. 技术报告：已验证结论、比较条件、限制和复现步骤。

平台标识使用 `metax-c500`。共享框架改动经两个平台负责人互审；本仓库既有BI-V150成绩不作为C500的基线或验证结果。总入口见 [团队首页](../../README.md)。
